1 Executive Summary

This feasibility report evaluates the viability of developing an Intelligent Resume-Job Matching & Skill Gap Advisory System — an AI-powered full-stack application that automatically scores how well a candidate's resume matches a given job description, using a combination of dense vector similarity, sparse keyword matching (BM25), and Large Language Model (LLM) analysis.

The system aims to solve a critical problem in the recruitment pipeline: the manual, time-consuming, and subjective process of evaluating resumes against job requirements. By automating this with AI, the system provides objective, quantifiable match scores and actionable skill-gap feedback for candidates.

✅ Overall Verdict: FEASIBLE After thorough analysis across technical, economic, operational, and schedule dimensions, this project is deemed fully feasible for development within the proposed 7-week timeline using open-source technologies and free-tier cloud services.

2 Project Overview

2.1 Problem Statement

Recruiters spend an average of 6–8 seconds scanning a resume. This leads to qualified candidates being overlooked and poor-fit candidates advancing. Candidates, on the other hand, have no way to objectively measure how well their resume matches a job before applying.

2.2 Proposed Solution

An AI-powered web application where users upload a resume (PDF) and paste a job description. The system then:

  • Extracts text and skills from the resume using NLP (spaCy)
  • Computes a dense match score using Sentence Transformers (vector embeddings)
  • Computes a sparse match score using BM25 keyword ranking
  • Generates a weighted hybrid score combining both methods
  • Uses Google Gemini LLM to provide personalized skill gap analysis and career advice

9 SWOT Analysis

💪 Strengths

  • Hybrid AI matching (dense + sparse) for high accuracy
  • Fully containerized — runs on any machine
  • Zero-cost tech stack (100% open source)
  • Modern, responsive React dashboard
  • Async processing prevents UI blocking

⚠️ Weaknesses

  • Requires Docker for local setup
  • LLM output quality depends on prompt engineering
  • CPU-only inference is slower than GPU
  • Single developer — limited bandwidth

🚀 Opportunities

  • Expand to multi-resume batch processing
  • Add support for LinkedIn profile import
  • Monetize via SaaS model for recruiters
  • Integrate with ATS platforms (Greenhouse, Lever)

🛡️ Threats

  • Gemini API rate limits or pricing changes
  • Competition from established ATS tools
  • Data privacy concerns with resume uploads
  • AI hallucination in skill gap advice
